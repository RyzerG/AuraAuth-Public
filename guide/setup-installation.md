# Setup & Installation

Because AuraAuth is distributed outside of the Google Play Store to maintain its independent, telemetry-free nature, you will need to install it manually via an APK file.

## 1. Download the APK
1. Navigate to the official [AuraAuth Releases page](https://github.com/RyzerG/AuraAuth/releases) on GitHub.
2. Under the latest version tag, click on `AuraAuth-vX.X.X.apk` to download the file directly to your Android device.

## 2. Enable Unknown Sources
If this is your first time sideloading an application on your device:
1. Open the downloaded `.apk` file.
2. Android will prompt you with a security warning stating your phone is not allowed to install unknown apps from this source.
3. Tap **Settings** on the prompt.
4. Toggle **Allow from this source** to the ON position.
5. Hit the back arrow to return to the installation screen.

## 3. Install and Launch
1. Tap **Install** on the AuraAuth prompt.
2. Once installed, tap **Open**.
3. You will immediately be greeted by your device's native Biometric prompt (Fingerprint or Face ID). Authenticate to access your new, empty vault.
