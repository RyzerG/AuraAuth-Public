# Getting Started

AuraAuth is an offline two-factor authenticator engineered for Android devices.

## Installation

1. Navigate to the [Releases](https://github.com/RyzerG/AuraAuth/releases) page on GitHub.
2. Download the latest `AuraAuth-vX.X.X.apk`.
3. Open the downloaded package on your Android device and confirm installation.

## Adding Accounts

AuraAuth supports automatic QR code ingestion and manual key entry:

* **QR Code Scanning**: Tap the **+** button on the bottom right and select **Scan QR Code** to use the camera interface.
* **Manual Setup**: Populate the **Issuer**, **Username**, and Base32 **Secret Key** fields directly in the creation dialog.
